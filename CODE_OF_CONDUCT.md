# Code of Conduct

This project expects professional, constructive collaboration.

## Standards

Acceptable behavior includes:

- Respectful technical disagreement
- Clear issue reports
- Constructive code review
- Good-faith participation

Unacceptable behavior includes:

- Harassment or abuse
- Personal attacks
- Doxing or private information disclosure
- Deliberate disruption

## Enforcement

Maintainers may remove comments, close issues, restrict participation, or take other reasonable moderation actions.
